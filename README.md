❤️ Heart Disease Prediction Using Machine Learning

📌 Project Overview

The Heart Disease Prediction project uses Machine Learning algorithms to analyze health-related data and predict whether a person may have heart disease.

The system uses patient-related information to classify the possibility of heart disease. It demonstrates how Machine Learning can support healthcare data analysis.

Note: This project is for educational purposes and is not a medical diagnostic tool.

🎯 Project Objectives

- Analyze heart disease datasets.
- Clean and preprocess the data.
- Identify important health-related features.
- Build classification models.
- Predict heart disease outcomes.
- Compare two Machine Learning algorithms.
- Evaluate model performance.

🧠 Algorithms Used

1. Support Vector Machine (SVM) – Main Algorithm

SVM is a supervised Machine Learning algorithm used for classification. It finds an optimal decision boundary to separate different classes.

Why SVM?

- Suitable for binary classification.
- Works with multiple input features.
- Effective for classification problems.
- Helps identify patterns in health data.

2. Logistic Regression – Comparison Algorithm

Logistic Regression is a supervised Machine Learning algorithm used to predict the probability of a class.

Why Logistic Regression?

- Simple and efficient.
- Suitable for binary classification.
- Provides probability-based predictions.
- Useful for comparing model performance.
